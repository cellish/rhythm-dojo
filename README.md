# リズム道場（Rhythm Dojo）

基本的なリズム感から、クラシック、ジャズ、ポップス・ロック・ファンク・ラテンで必要なリズム感までを、キーボード（またはタップ）で叩いて練習するブラウザ用アプリです。1打ごとのずれを ms 単位で測り、メーターとグラフで結果を見せます。

## 内容

| 編 | モード |
|---|---|
| 入門編 | 一定拍、消えるメトロノーム、チェンジアップ、ポリリズム、リズム模倣、テンポ変化の聴き分け |
| クラシック編 | ルバート、付点・複付点、ヘミオラ、変拍子、入り（指揮） |
| ジャズ編 | スウィング・フィール、クリックを減らす、ノリの位置、コンピングのリズム、重ねリズム |
| ポップス・ラテン編 | 16ビート、シンコペーション、ハーフ／ダブル、シャッフル ⇄ イーブン、ラテン、キックになる |

テンポ変化の聴き分け以外のモードには、易しい順に並べた練習ステップがあります。
