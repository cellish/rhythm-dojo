# リズム道場（Rhythm Dojo）

基本的なリズム感から、クラシック、ジャズ、ポップス・ロック・ファンク・ラテンで必要なリズム感までを、キーボード（またはタップ）で叩いて練習するブラウザ用アプリです。1打ごとのずれを ms 単位で測り、メーターとグラフで結果を見せます。

## 内容

| 編 | モード |
|---|---|
| 入門編 | 一定拍、消えるメトロノーム、チェンジアップ、ポリリズム、リズム模倣、テンポ変化の聴き分け |
| クラシック編 | ルバート、付点・複付点、ヘミオラ、変拍子、入り（指揮） |
| ジャズ編 | スウィング・フィール、クリックを減らす、ノリの位置、コンピングのリズム、重ねリズム |
| ポップス・ラテン編 | 16ビート、シンコペーション、ハーフ／ダブル、シャッフル ⇄ イーブン、ラテン、キックになる |

テンポ変化の聴き分け以外のモードには、易しい順に並べた練習ステップがあります。

### 収めているリズムパタンと和声進行

他人の作品の旋律や歌詞は収めていません。アプリの中で鳴る型は、次のとおりです。

| 内容 | 出どころ | 状態 |
|---|---|---|
| クラーベ（ソン／ルンバ、3-2・2-3）、トレシージョ、ボサノヴァのクラーベ、6/8 のベルパタン | キューバ・ブラジル・アフリカ系の伝統的なリズムの型 | 特定の作者のいない伝統的な型。作者が拍の位置を組み立てたもの |
| コンピングのリズム（チャールストンなど）、シンコペーションの型、ドラムの型（8ビート、16ビート、ファンク、ハーフタイムなど）、キックの型 | ジャズ・ポップスで広く使われる慣用的な型 | 作者が組み立てたもの |
| ウォーキングベース（F のブルース進行の上でランダムに生成）、ピアノ伴奏の和声進行（ハ長調の I–IV–V–I など） | 慣用的な和声進行 | 作者が組み立てたもの。ベースの音は毎回プログラムが作る |
| リズム模倣の出題、お手本のメロディ（音階の上り下り） | アプリがその場で作るもの | 作者自身の作品 |
